# AKSH — Heal Within. Grow Beyond.
A responsive cinematic mental-wellness website designed for GitHub Pages.

## Publish on GitHub Pages
1. Download and unzip `AKSH_Fresh_Website.zip`.
2. Open your `aksh-mental-wellness` GitHub repository.
3. Upload the **contents** of this folder (not the outer folder): `index.html`, `assets/`, `css/`, `js/`, and `README.md`.
4. Commit to the `main` branch.
5. In Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.

## Included interactions
- Responsive navigation and reveal animations
- Opt-in generated ambient tones (no external audio file needed)
- Companion chat demo, browser speech input where supported, and language preference selector
- FAQ accordions and mailto contact links

## Notes
The companion currently demonstrates front-end interactions only; it is not connected to a live AI service. Replace the sample email/social links with verified official destinations before launch. Ambient sound is synthesized locally and starts only after the visitor presses the music control.
